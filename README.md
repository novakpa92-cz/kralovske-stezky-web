# Královské stezky – webová hra

Veřejná část webu hry na **https://hra.libricivitatis.eu** (GitHub Pages).

- Obsah je kopie složky `www/` z herního repozitáře (soukromý `kralovske-stezky`).
- Jediný rozdíl: v `index.html` je `data-api="https://libricivitatis.eu/stezky-api.php"` (HTTPS most k botovi na Endoře).
- Obrázky a zvuky se načítají z `kralovske-stezky-grafika` (GitHub Pages).
- Nejsou tu žádná data, tokeny ani kód bota — jen to, co si prohlížeč stejně stáhne.
